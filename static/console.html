Rounds

Pick 1–12 rounds. Each is a category to generate (10 questions by default, up to 40) or a saved library round. Configure before you start. Round 1 is playable as soon as it's ready.

Import questions

Paste or upload questions in almost any format: one per line, a Quizlet export, a spreadsheet or CSV, Q:/A: blocks, lettered A) B) C) choices, or JSON. Saving needs no AI. Afterwards choose Library in Rounds above to use the round.
Quizlet sets sometimes have them backwards. Files up to 200 KB.

AI help (optional)

With an AI model set up, it can finish half-done rows (a question with no answer, an answer with no question, no wrong choices) or write fresh questions from notes. Your question and answer text is kept word for word. AI-written answers are not fact-checked, so skim them before play.
